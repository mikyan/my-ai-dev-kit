# Repository Guidelines

## Purpose

This repository stores reusable AI development assets: Skills, plugins, Prompts, and workflows.

## Rules

- Use Chinese for explanations; retain original technical names when useful.
- Store each complete asset in its matching directory and add it to that directory's index.
- Prefer the smallest instruction set that reliably changes Agent behavior.
- Describe conditions and the resulting design choice directly.
- Update obsolete conclusions in place; do not add defensive explanations about discarded alternatives.
- Keep project-specific facts, generated reports, temporary experiments, credentials, tokens, private URLs, and personal data out of the repository.
- Before publishing an asset, state its use case, inputs, outputs, constraints, and status.
- Do not claim an asset is validated unless it has been exercised in a real task or a recorded evaluation.
